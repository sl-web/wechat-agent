# 系统使用与联调指引(2026-09-09)

## 环境
- venv:`.venv`(Python 3.13)
- 依赖已装:fastapi/uvicorn/playwright/openai/apscheduler/bs4 等
- 敏感配置:复制 `.env.example` 为 `.env` 后填写

## 启动服务

**Windows 推荐直接双击项目根目录的 `start_backend.bat`**(前台运行,日志直接可见)。

```bash
.venv/Scripts/python -m uvicorn app.main:app --port 8000
# 浏览器访问 http://127.0.0.1:8000/health 等
```

> ⚠️ **后端必须在一个"持续存活"的终端里启动**(普通 PowerShell / CMD 窗口,或 `start_backend.bat`)。
>
> 公众号扫码/推送依赖 Playwright,它跑在**独立子进程**里。如果后端是被"一次性脚本或沙箱命令"
> 拉起的、拉起它的那个进程随后就退出了,那么**后端所在的 job 会被回收,此后它派生的任何子进程
> 都会被立即杀掉**。表现就是点「扫码登录」时工作进程秒退、二维码窗口根本弹不出来。
>
> 识别特征:**重启后端后的第一次操作能成功,之后每次都失败**;工作进程退出码 1 且零日志输出。
> 诊断接口:`GET /api/pusher/diagnose`(`spawn` 字段可判断能否正常派生子进程)。

## 已实现的 API(前缀 /api)
| 方法 | 路径 | 功能 |
|------|------|------|
| GET | /health | 健康检查 |
| GET/POST | /config[/key] | 配置读取/写入(控制面板) |
| GET/POST | /templates[/tid] | 模板列表/保存/启停/删除/seed |
| GET | /review/queue?status= | 审核队列(pushed/pending_review/...) |
| GET | /review/articles/{aid} | 稿件全文+来源热点 |
| POST | /review/approve|reject|edit|publish/{aid} | 审核四动作 |
| POST | /clean | 知识库清理(合规/重复/低价值) |
| POST | /hot/delete-by-url | 一键删稿 |
| GET | /dashboard[/stale] | 运营看板/滞留告警 |
| POST | /pipeline/{stage} | 手动触发流水线环节(fetch/analyze/generate/push/backfill/clean/all) |
